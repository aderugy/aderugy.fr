### Listes avec répétition

Une **liste** (ou $k$-uplet) d'éléments de $E$ est un élément de $E^k$ : $k$
positions ordonnées, répétitions permises. Par la règle du produit,

$$
\operatorname{card}(E^k) = n^k \qquad (n = \operatorname{card} E).
$$

Il revient au même de compter les **applications** de $\{1, \dots, k\}$ dans
$E$ : une application est la liste de ses valeurs. Le nombre d'applications
d'un ensemble à $k$ éléments dans un ensemble à $n$ éléments est donc $n^k$ —
c'est la raison de la notation $E^F$ pour l'ensemble des applications de $F$
dans $E$.

### Arrangements

Un **arrangement** de $k$ éléments de $E$ est une liste de $k$ éléments
**distincts** de $E$ — autrement dit une injection de $\{1, \dots, k\}$ dans
$E$. Le premier élément se choisit parmi $n$, le deuxième parmi les $n - 1$
restants quel qu'ait été le premier, et ainsi de suite :

$$
A_n^k = n (n-1) \cdots (n-k+1) = \frac{n!}{(n-k)!} \qquad (0 \le k \le n),
$$

et $A_n^k = 0$ si $k > n$. Le cas $k = n$ compte les **permutations** de $E$,
les bijections de $E$ dans lui-même : il y en a $n!$, avec la convention
$0! = 1$ — il existe exactement une bijection de l'ensemble vide dans
lui-même, l'application vide.

Le produit $n(n-1)\cdots(n-k+1)$ est la forme à utiliser en calcul : la forme
$n!/(n-k)!$ fait passer par des nombres gigantesques pour rien, et c'est elle
qui déborde en flottants.

### Piège : la règle du produit exige un nombre de choix constant

Combien de nombres à trois chiffres distincts, sans zéro en tête ? Choisir
d'abord le chiffre des unités ($10$ choix), puis celui des dizaines ($9$), puis
celui des centaines — mais leur nombre dépend de ce qui précède : $7$ si le
zéro a déjà été utilisé, $8$ sinon. La règle du produit ne s'applique pas dans
cet ordre. Dans l'autre ordre, elle s'applique : centaines ($9$ choix, tout
sauf zéro), puis dizaines ($9$ : le zéro redevient permis, le chiffre des
centaines non), puis unités ($8$) — soit $648$. **L'ordre dans lequel on
construit l'objet est libre ; il faut choisir celui où le nombre de choix ne
dépend pas des choix précédents.**

### Vérification par énumération

Sur de petites valeurs, l'énumération est possible et valide les formules.

```python
from itertools import permutations, product
from math import factorial, perm

n, k = 6, 3
E = range(n)
print("listes      :", sum(1 for _ in product(E, repeat=k)), "=", n**k)
print("arrangements:", sum(1 for _ in permutations(E, k)), "=",
      factorial(n) // factorial(n - k), "=", perm(n, k))

# Nombres a trois chiffres distincts, sans zero en tete
ok = [x for x in range(100, 1000) if len(set(str(x))) == 3]
print("trois chiffres distincts:", len(ok), "= 9*9*8 =", 9 * 9 * 8)
```

Sortie obtenue :

```
listes      : 216 = 216
arrangements: 120 = 120 = 120
trois chiffres distincts: 648 = 9*9*8 = 648
```

Le module standard `math` fournit `perm(n, k)` et `comb(n, k)`, en entiers
exacts : on les préférera toujours à une formule écrite avec des factorielles
flottantes.
